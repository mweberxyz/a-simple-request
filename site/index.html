The useful question isn't "did a machine type this?"
It's "did the person named here actually look at this?"

The problem

Your name is only worth what you put behind it.

Trust gets used up quietly

Peers learned that your name means you thought about something. Agent output nobody reviewed uses up that trust, and you don't see it happening.

Reviewing everything defeats the point

The only safe option today is to read every message before it goes out, which takes away most of the reason to delegate.

So readers trust everything less

When nobody can tell which comments got a person's attention, every comment gets less trust. That's part of why GitHub feels hostile lately.

This is already happening

Developers are working around it one repo at a time.

Footers, signature lines, labels, separate bot accounts. Each project invents its own format and relies on the honor system, and none of them can mark an approval, a merge, or a label change.

The proposal

Four small pieces.

1

The credential says it's an agent

When you create a token, authorize an app, or run gh auth login, choose Personal (the default) or Agent. It's fixed when the credential is created, so the agent can't remove the tag.

2

A tag next to your name

Everything an agent session creates gets a small agent tag, like the existing bot label. It's still your account and still your responsibility, and it's honestly labeled.

3

Endorse as mine

Review an agent's comment or PR and endorse it. The tag goes away, and the timeline records that you did. Review what matters and let the rest go out tagged.

4

Readers choose what they see

Show, collapse, or hide unreviewed agent activity per repo, in notifications, and in the API. Maintainers get a signal they can actually use.

What this isn't

No detection, no shaming, no new accounts.

  • Not AI detection.The tag comes from what you declared about the session. Nothing guesses from the text.
  • Not a penalty.Agent sessions keep the same permissions. The tag only says whether a person reviewed the content.
  • Not bot accounts.Bot accounts break the link to the responsible person. This keeps that link.

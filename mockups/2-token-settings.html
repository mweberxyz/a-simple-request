The credential sets the session type, not the client

1

Chosen when you create the credential. The same choice belongs on the OAuth / GitHub App authorization screen, on SSH keys, and in gh auth login --agent.

2

The agent can't remove it. A tag the client sets on itself is easy to skip. A tag tied to the credential is reliable. "Personal" stays the default, so nothing changes for anyone who doesn't opt in.

3

Named for the person, not the vendor. You choose the label, so you can tell your own agents apart.
